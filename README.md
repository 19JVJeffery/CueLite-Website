# CueLite-Website

A full showcase website for the CueLite app.

## GitHub Pages hosting

The site is deployed automatically with GitHub Actions whenever changes are pushed to `main`.

After enabling GitHub Pages for this repository (Source: **GitHub Actions**), the site will be served at:

`https://19JVJeffery.github.io/CueLite-Website/`

## Local preview

```bash
npm start
```

Then open `http://localhost:4173`.
