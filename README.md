# CueLite-Website

A full showcase website for the CueLite app.

## GitHub Pages hosting

The site is deployed with GitHub Actions to GitHub Pages on every push to `main`.

After enabling Pages in repository settings (Build and deployment source: **GitHub Actions**), the site will be available at:

`https://19jvjeffery.github.io/CueLite-Website/`

## Local preview

```bash
npm start
```

Then open `http://localhost:4173`.
